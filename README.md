# 🎮 Video Game Sales Analysis and Prediction

This project analyzes global video game sales using Python and visualizes key insights with Power BI. It also uses a Linear Regression model to predict global sales based on regional sales data.

The goal of this project was to practice data cleaning, exploratory data analysis (EDA), machine learning, and dashboard creation using real-world data.

---

## 📌 Features

- Cleaned and preprocessed raw sales data
- Analyzed sales across different game genres
- Visualized genre-wise global sales using Matplotlib
- Built a Linear Regression model for sales prediction
- Created an interactive Power BI dashboard
- Exported cleaned and predicted datasets

---

## 📊 Dataset

This project uses the **Video Game Sales Dataset** from Kaggle, which contains information such as:

- Game Name
- Platform
- Genre
- Publisher
- Year of Release
- Regional Sales (NA, EU, JP, Other)
- Global Sales

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/gaming-project.git
```

2. Install the required libraries

```bash
pip install -r requirements.txt
```

3. Run the scripts

```bash
python analysis/data_cleaning.py
python analysis/analysis.py
python analysis/sales_prediction.py
```

4. Open `gaming_dashboard.pbix` in Power BI Desktop to explore the dashboard.
